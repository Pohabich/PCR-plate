# PCR-plate
This module is the central part of the GUI for the SavvyGen H.pylory and SavvyGenRTPCR projects. This is a family of desktop applications developed for the detection of infectious diseases based on DNA.
The workflow consists of the following steps: data acquisition, display for correction, analysis (calculations), and display of results.
The module was designed to participate in two of these steps: display for correction and display of results.
Due to medical data security requirements, developing a web version is never considered.
This project has a single target: to develop a self-contained web module with minimal external dependencies using basic web-stuff only   HTML, CSS and JavaScript.

Project goals
1.	Create a custom context menu
2.	Manage it based on the current state
3.	Handle cross-event statuses
4.	Manage styles based on the current state
5.	Work with special data types (Enum)
6.	Structuring
